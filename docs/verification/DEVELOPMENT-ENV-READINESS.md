## 개발 전 남은 결정

- 안전한 버스 API 접속 주소·인증 방식·현재 무료 이용/호출 제한을 확인한다. 서비스 API 호출 0건 유지.
- TASK-002 공공 ID·좌표·방향·순서·시각 실측을 완료하지 않았다. 미검증 모델을 앱 타입으로 확정하지 않는다.
- React/TypeScript/Vite는 기존 제안이며 확정 스택으로 간주하지 않는다. 기본 도구가 있으므로 사용자에게 재설치를 요구하지 않는다.
- 지도·장소·도보 공급자와 무료 자격·외부 위치 처리 조건은 미결정. 후보 키를 일괄 발급하거나 유료 계정·호스팅·DB를 만들지 않는다.
- TASK-003 앱 작성, 테스트/빌드, 배포는 미실행. 로컬 저장소의 git status는 빈 출력으로 유지된다.
