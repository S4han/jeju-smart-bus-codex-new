# 제주 BIS 정류소 좌표계 확인 문의 초안

작성일: 2026-10-29 (Asia/Seoul). **저장소 문서로만 보관, 미발송.** 이메일·민원·게시판 등록이나 전화 문의를 수행하지 않았다. 문의 발송 승인을 반복 요청하지 않는다.

문의 대상: 제주 BIS OpenAPI 제공 담당 부서. 담당 수신 주소는 미확인으로 남긴다. [제주 공식 OpenAPI 안내](https://www.jeju.go.kr/help/open.htm?act=view&seq=967654)는 기존 제공 경로이며, 이번 확인 도구에서는 원문 접근에 실패했다. 연락처를 추정하지 않는다.

## 제목

제주 BIS OpenAPI Station의 localX/localY 좌표계·순서·단위 확인 요청

## 본문

안녕하세요. 제주 BIS 공개 정류소 정보를 이용하는 신규 버스 안내 웹앱을 개발하고 있습니다. 반경 검색과 지도 배치에 사용할 정류소 좌표의 기준을 확인하고자 합니다.

대상은 `busopen.jeju.go.kr`의 `/OpenAPI/service/bis/Station` 응답에 포함되는 `localX`, `localY`입니다. 제주데이터허브 정류소 기본정보 API의 `longitude`, `latitude`나 TAGO 응답과 구분하여 아래 사항을 확인 부탁드립니다.

1. `localX`와 `localY`의 측지계와 좌표계는 무엇인가요? WGS84 경위도라면 EPSG:4326인지, 다른 기준이라면 적용되는 EPSG 또는 공식 정의를 알려주세요.
2. 필드 순서는 `localX=경도`, `localY=위도`이고 단위는 십진 도(degree)인가요? 변환 없이 GPS 경위도와 거리 계산·지도 표시에 사용해도 되는지 확인 부탁드립니다.
3. 정류소별로 다른 좌표계가 섞일 수 있나요? 제주 본섬과 추자도 등 도서 지역에도 같은 기준이 적용되나요?
4. 좌표 오류가 의심되는 정류소 ID `406002082`가 있습니다. 앱에서 값을 임의 교환하지 않고 좌표 미확인으로 제외할 예정인데, 정정 현황 또는 오류 신고 경로가 있나요?
5. 좌표를 포함한 정류소 정보의 `upd`는 어떤 항목의 갱신시각인가요? 좌표 기준일 또는 좌표 변경 여부 확인에 사용할 수 있나요?

적용되는 공식 명세의 URL·버전 또는 해당 필드에 대한 담당 부서의 안내를 부탁드립니다. 사용자 위치나 인증정보는 문의에 포함하지 않았습니다. 감사합니다.

## 답변 수신 후 판정 절차

- 답변이 해당 BIS Station 필드를 명시하는지 확인하고 출처·확인일을 기록한다. 다른 API/시설의 좌표계를 자동 승계하지 않는다.
- 측지계·축 순서·단위가 확인되면 이미 확보한 공개 정류소 원문을 오프라인으로 다시 검증한다. 범위 오류·비활성·중복 ID를 분리하며 값을 임의 교정하지 않는다.
- 그 결과를 GATE-01에 반영한 뒤 로컬 500m 검색, 0건일 때 해당 위치에만 동의 후 1km 확대, 지도·목록 공통 집합 순으로 구현·검증한다. 지도 SDK는 별도 PRIV-004 조건을 따른다.
- 이 초안 작성은 GATE-01 통과 또는 추가 API 호출 승인이 아니다. 기존 누적 13/13회는 유지한다.
