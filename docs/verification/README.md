# 검증 기록 규칙
초기 PRIV-001~004, GATE-01~06 상태: 모두 미검증.
게이트별 문서에 ID, 확인일시/환경, 공식 출처 URL·확인일, 요청 목적·개수(키 제외), 응답 항목·단위·좌표계·신선도·정합성, 비식별 표본, 판정(통과/부분/보류), 영향 FR/AC, 후속 작업을 기록한다.
실호출 증거와 합성 단위 테스트를 구별한다. 공개 정류장 좌표와 사용자 위치를 구별하되 사용자 위치·키·인증 URL·원문 로그는 공개하지 않는다.
현재 환경·서비스 조건이 달라지면 이전 검증을 그대로 통과 처리하지 않는다.
게이트 통과와 해당 FR 구현 완료, 전체 출시 승인은 각각 별도 판정한다.
