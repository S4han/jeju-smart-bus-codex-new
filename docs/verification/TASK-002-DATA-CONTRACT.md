# TASK-002 실측 기반 데이터 처리 계약 초안

작성일: 2026-10-28T20:41:37+09:00. AI 제안이며 앱 구현·신규 정책 승인으로 취급하지 않는다.
근거: [실측 기록](TASK-002-LIVE-BIS.md). 사용자 위치·비밀키 없이 얻은 공공 데이터만 사용했다.

## 조회와 파싱

- 공식 HWP의 HTTP/XML API를 서버 검증에서 무키로 조회 가능함을 확인했다. JEJU_BUS_API_KEY는 현재 검증 호출에 불필요하며 삭제·변경하지 않는다. 브라우저 직접 HTTP 호출 구조는 채택하지 않는다.
- 응답 전체 수신·XML 파싱 성공·resultCode=00을 별개로 검사한다. HTTP 200만으로 성공 처리하지 않는다. resultCode 00의 빈 목록은 정상 빈 응답으로 구분한다.
- 크기·시간 제한, 재시도 없음, 리다이렉트 자동 추적 없음이 검증 호출의 경계다. 전체 StationRoute 32 MiB 제한 초과는 잘린 데이터로 처리한다. 불완전 파일을 완전 스냅샷으로 배포하지 않는다.
- numOfRows/totalCount만 믿고 임의 파라미터나 페이지 순회를 추가하지 않는다. 이번 전체 응답이 크다는 사실만으로 페이징 지원·전체 크기·갱신 전략을 확정하지 않는다.

## 미확정 데이터에 대한 안전 동작 제안

- 좌표 오류 ID 406002082는 교환 추정으로 수정하지 않고 좌표 미확인으로 구분한다. 정류장 이름·ID의 존재와 지도 배치 가능성은 분리한다. 실제 좌표계 EPSG는 미확정이다.
- routeTp=53 및 useYn=A 등의 의미는 미확정이다. 모르는 코드를 이미 아는 일반 버스 유형으로 변환하지 않는다.
- 경유 정류장이 1개 이하인 노선, 정합성 불명 노선은 추천 후보로 바로 채택하지 않는다. 운영 필터 기준은 별도 결정이 필요하다.
- updnDir=0만 관찰했으므로 그것을 왕복 양방향 지원 증거로 쓰지 않는다. 같은 이름의 정류장을 ID 확인 없이 합치지 않는다.
- 반복 방문은 stationId가 같아도 stationOrd별 개별 사건으로 취급하는 설계 후보다. 이번 활성 두 노선에 반복이 없다고 모든 노선에서 불필요하다고 판단하지 않는다.
- 도착정보의 차량 ID=0, 예측시간=0을 즉시 도착으로 표시하지 않는다. 차량 없음 의미는 미확정으로 유지한다. 현재 차량 3행의 예측시간은 4/8/50이며 단위 분은 공식 문서 근거다.
- 2024년 산출행이 섞인 응답을 전체 실시간으로 표시하지 않는다. 정확한 신선도 임계치는 미확정이며 Claude의 120초를 자동 채택하지 않는다. 수신시각 기록을 향후 관측에 포함한다.
- 정상 빈 응답을 전체 서비스 장애나 버스 미운행으로 단정하지 않는다. 부분 관계 검증 1/42행을 전체 도착정보 통과로 표시하지 않는다.
- 첫·막차·배차 간격만으로 정류장별 시간표·버스 구간 소요시간을 만들지 않는다. 직선거리와 임의 속도로 도보시간을 대체하지 않는다.

## 개발 준비와 잔여 조건

기본 도구 Node/npm 및 패키지 접근 준비는 완료되었다. 데이터 조회도 현재 환경에서 가능하다. 새 개발을 위해 키나 허용 도메인을 다시 설정할 필요는 확인되지 않았다.

| 항목 | 상태 | 다음 조치 |
|---|---|---|
| 기본 버스 연결 | 실측 성공 | 제공기관 문의를 선행 필수로 두지 않음 |
| 정류장 ID·좌표 | 부분 | 좌표계·오류 제외·지도 표시 기준 검토 |
| 노선 순서·관계 | 두 표본 부분 | 전체 응답 취득 전략을 크기·메모리·호출 예산과 함께 재설계 |
| 도착 시각 | 산출시각·과거행 혼재 확인 | 행별 매핑·신선도 정책 검토 |
| 시간 추천 | 보류 | 도보/버스구간/환승 원천과 산식 필요 |
| 지도·장소·도보 | 미선택 | 0원·외부 위치 처리 조건 확인 필요 |
| 앱 코드·스택 확정 | 미착수 | 코드 변경 금지 지시 유지. React/TypeScript/Vite는 후보 |

## 추가 호출 없이 준비한 다음 검증 계획

- 전체 StationRoute의 응답 크기 제한을 무작정 올리지 않는다. 증분 last의 의미·현재 응답 방식·메모리 한도를 조사하고, 스트리밍 요약이나 필요한 노선 표본 확장 중 범위에 맞는 방식을 선택한다.
- 크기 제한 중단 조건에 따라 현재 세션의 추가 서비스 API 조회는 중단했다. 이후 호출 계획은 누적 9/13회를 보존하며 별도로 갱신해야 한다.
- 단위 테스트용 합성 데이터는 유효성 로직 테스트에만 사용하며 실측 게이트 증거로 쓰지 않는다. 현재 앱 테스트·빌드는 실행하지 않았다.
- 기존 저장소 결정·지도 키 예외·Vercel 설정·신선도 임계치를 자동 이식하지 않는다. 기존 저장소와 Vercel은 계속 변경하지 않는다.
