## 연결 판단 정정

Claude 소스는 HTTP의 busopen.jeju.go.kr/OpenAPI/service/bis/에 키 없이 요청한다. 기존 성공 기록을 새 프로젝트의 통과 증거로 이식하지 않고, 현재 환경에서 같은 공식 주소의 공공 데이터 최소 조회를 수행했다. 제공기관 문의는 기본 연결의 필수 조건이 아니었다. HTTPS·키 필요성 미해결을 이유로 공개 데이터의 무키 HTTP 조회 가능성을 충분히 검토하지 못한 앞선 판단을 정정한다.

HTTP 응답은 전송 무결성이 TLS로 보호되지 않는다. 비밀키와 사용자 위치는 전혀 전송하지 않았다. 이 연결 성공이 민감정보 전송이나 운영 보안·비용 검증 완료를 뜻하지 않는다. 인증서 검증을 끄거나 HTTPS 정책을 우회한 것이 아니라 공식 HWP에 기재된 HTTP 조회 방식을 사용했다.

## 전체 매핑 제한 및 오프라인 추가 검증 — 2026-10-28T20:41:37+09:00

9번째 StationRoute 요청은 HTTP 200이지만 응답이 32 MiB 제한에 도달해 curl exit 63으로 종료되었다. 응답이 완결되지 않아 XML 파싱·전체 건수·정합성 검증에 사용하지 않았다. 공급자 장애가 아니라 검증기가 정한 크기 제한이며 응답 전체 크기는 미확인이다. 계획대로 반복·추가 API 호출을 중단했다. 총 요청 9/13회, 정상 완결 응답 8회, 크기 제한 중단 1회. 앞선 8회 성공 수치는 유지한다.

오프라인 추가 실측:
