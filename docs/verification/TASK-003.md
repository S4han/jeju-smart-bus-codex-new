## 사용자 승인과 상태

사용자가 새 저장소의 React·TypeScript·Vite 앱/테스트/빌드 작성에 명시적으로 동의했다. 기존 두 저장소와 Vercel 변경은 금지 유지. 이전 앱 코드 금지 지시는 새 저장소의 이 기반 범위에서 해제되었다.

판정: **부분 — 앱·검증·빌드 기반 통과, U-003 안정 경로 ID 사용자 확인 대기.** GATE-01~04 부분, GATE-05 보류, GATE-06 부분 및 PRIV 기존 판정을 유지한다. 버스 앱 기능/MVP 완료가 아니다.

## 구현

- Node 24, React/React DOM, TypeScript/Vite, Vitest. package-lock.json으로 해석된 설치 버전 고정. .nvmrc/.gitignore/.env.example 구성.
- 준비 상태의 한국어 반응형 화면, 검색 버튼 비활성. 가짜 정류장·노선·시간 표시 없음.
- src/domain에 결과 상태와 정류장·정차 사건 검증을 UI/네트워크와 분리. 실측 필드에 근거하고 좌표계 미확정·알 수 없는 상태를 보존한다. 반복 방문은 순번별 사건으로 분리 가능하게 한다.
- 산출시각의 명시적 시간대·유효 달력·미래시각 검사. 신선도 정책이 없으면 실시간 판정하지 않는다. 운영 임계치 미채택.
- 네트워크/XML 어댑터는 아직 도입하지 않았다. 도메인 파서는 이미 검증된 행을 받는 순수 함수다. 전체 XML 수집·서버 중계 완료라고 주장하지 않는다.
- CSP connect-src none, 외부 SDK 없음. 비밀 env 접근·위치/영구저장 API·통신 API 참조를 소스와 빌드 산출물에서 검사한다. 현재 설정 비밀값과 일치하는 번들 내용도 값 출력 없이 검사한다. 이 정적 검사는 모든 우회·향후 코드 안전성을 증명하지 않으며 기능 추가 시 갱신한다.

## U-003 제안과 잔여

경로 ID 제안: 버전 + 순서 있는 각 구간의 노선 ID·방향·승차순번·하차순번. 사용자 좌표 미포함. 사용자 답변 전 실제 경로 ID/정렬 코드를 작성하지 않았다. 실수로 중국어로 표시한 질문은 한국어로 정정했으며 승인으로 처리하지 않는다.

관련 NFR-003/004/006. FR/AC 기능 활성화 없음. TASK-004 위치 기능은 PRIV/지도 조건, TASK-005 경로 기능은 관계 게이트, TASK-006 시간 기능은 원천/산식 조건 전 착수하지 않는다. 필요한 사용자 결정을 확인한 다음 허용 범위를 계속 수행한다.

## U-003 승인 및 TASK-003 종료 판정
