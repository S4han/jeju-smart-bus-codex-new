## TAGO 공공 표본 1회 검증 제안 — 선택 사항·미승인·미실행

2026-10-29 정정: TAGO는 필수 서비스가 아니다. 이 제안 때문에 사용자에게 가입/키 등록을 요구하거나 TASK-004 전체를 TAGO 승인 대기로 처리하지 않는다. 기존 제주 공식 자료를 우선한다. 아래 조건은 향후 TAGO를 선택하는 경우에만 적용된다.

목적: 명세에 WGS84가 명시된 응답을 받아 제주 공공 정류장 표본과 대조할 수 있는지 확인한다. 이 한 번으로 BIS 전체의 좌표계나 두 공급자의 전체 ID 관계가 검증된다고 주장하지 않는다.

### 실행 전 필요한 조건

1. 계정에서 **국토교통부_(TAGO)_버스정류소정보**의 활용신청/승인이 실제로 완료됐고 사용할 키에 적용된다는 확인. 기존 변수 이름 `JEJU_BUS_API_KEY`만으로 해당 서비스의 권한을 추정하지 않는다. 키 값은 채팅/문서/명령행으로 받지 않는다.
2. 기존 13회와 별도로 추가 **최대 1회** 호출에 대한 사용자 승인. 승인 시 전체 공공 버스 검증 누적 상한은 14회이며, 기존 BIS 13회 이력은 그대로 유지한다. 실패 시 자동 재시도/도시코드·추가 정류장 조회 없음.
3. 관리 환경에서 실제 API 목적지 `apis.data.go.kr`에 대한 지원되는 허용 설정 확인. 현재 허용 목록에 없으므로 정책 우회/프록시 해제/인증서 검증 해제를 하지 않는다. 필요한 경우 이 호스트 하나만 별도 설정 대상으로 안내한다.

### 승인·준비 완료 후의 정확한 요청

- 공식 명세의 HTTPS `BusSttnInfoInqireService/getCrdntPrxmtSttnList` 1회. pageNo=1, numOfRows=10, _type=json.
- 좌표는 이미 확보한 **공공 정류장 ID 406000191**의 Station localX/localY 숫자를 대조 가설로 사용한다. 사용자 GPS/선택 목적지는 사용하지 않는다. 이 숫자가 WGS84로 검증됐다는 전제가 아니라, 주변 결과의 공공 ID/명칭/명시된 WGS84 좌표와 대조할 수 있는지 보는 제한된 실험이다.
- API키는 확인된 서버 환경변수에서 요청 처리 메모리에만 사용한다. 요청 URL·키·예외 원문을 로그/출력/커밋하지 않는다. 클라이언트/VITE 변수로 옮기지 않는다.
- 20초/2 MiB 상한, 리다이렉트·재시도·추가 페이지 요청 없음. 인증·쿼터·HTTP·형식 오류 또는 빈 결과면 그대로 기록하고 중단한다.
- 검증 항목: 실제 제주 지원 여부, 응답 필드/단위, 반환 ID/명칭, 현재 BIS 표본과의 차이/모호성. 이름 일치만으로 ID를 합치지 않고 nodeid 접두사 제거 같은 임의 매핑도 운영 코드로 확정하지 않는다.
- 성공해도 원문/키를 앱에 배포하지 않고 비식별 집계와 판정만 남긴다. 운영 원천 채택·전체 데이터 조회·개인 위치 전송·지도 SDK 활성화는 별도 조건을 따른다.

## 사용자만 확인 가능한 항목

TAGO 서비스별 활용승인 여부는 현재 연결 도구나 변수 이름으로 확인할 수 없다. 이 항목만 사용자에게 확인하며, 이미 완료된 NAVER 계정/Client ID 설정은 다시 요청하지 않는다. 신규 서비스키 발급이 필요하다고 미리 단정하지 않는다. 추가 요청 승인이 없으면 실제 호출하지 않는다.

이번 변경은 조사/조건부 계획 문서뿐이다. 앱 코드·의존성·PRD·lockfile 변경 없음. 이전 120개 테스트를 재실행 결과로 표기하지 않는다.
