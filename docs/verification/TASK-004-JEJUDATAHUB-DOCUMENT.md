# TASK-004 — 사용자 제공 정류소 기본정보 API 문서 검토

확인일: 2026-10-29 (Asia/Seoul). 사용자가 첨부한 `버스정류소기본정보API.hwp`의 본문을 로컬에서 추출해 검토했다. API 호출은 하지 않았다.

## 확인된 명세

- 문서: 버스 정류소 기본 정보 API 가이드, Version 1.0, 2020.12.
- 공급 경로는 **제주데이터허브**다. TAGO 버스정류소정보 또는 현재 사용한 BIS Station API와 다른 서비스다.
- 제주데이터허브 로그인 → 데이터를 프로젝트에 담기 → 마이페이지/프로젝트 관리의 프로젝트키 사용을 안내한다. 기존 `JEJU_BUS_API_KEY`가 이 프로젝트키라는 증거는 없다.
- HTTPS 호스트는 `open.jejudatahub.net`이며, 문서의 요청 경로는 `/api/proxy/DD11ab6a6t11D16baaa1a2tD26ata161/{your_appkey}`다. 인증값이 URL 경로에 들어가므로 요청 URL·오류·접근 로그 노출을 별도로 통제해야 한다. 실제 키는 문서/코드/명령행에 넣지 않았다.
- 공통 매개변수는 `number`(기본 1), `limit`(기본 10, 최대 100), 정류소 조회는 `stationName`이다. 응답은 `totCnt`, `hasMore`, `data`다.
- 정류소 예시 필드는 `stationId`, `stationType`, `stationName`, `stationAddress`, `direction`, `longitude`, `latitude`, `localInfo`이며, 좌표 예시는 문자열이다.
