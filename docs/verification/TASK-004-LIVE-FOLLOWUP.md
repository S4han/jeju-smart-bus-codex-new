### 확보 응답의 기존 도메인 파서 실데이터 검사

추가 네트워크 요청 없이 XML을 Python 표준 ElementTree로 디코딩하고, 임시 JSON 행을 기존 `parseStation`에 전달했다(Node 24의 타입 제거 실행). 앱 데이터/번들에 추가하지 않았다.

- 전체 4,816행 중 4,815행 파싱, 형식 거부 1행. 거부된 공개 정류장 ID 406001289는 useYn=N이며 stationNm/dirTp/govNm 결측이다. 이름을 생성하거나 이전 이름으로 보정하지 않았다.
- 파싱된 사용 Y 4,352행 / N 463행 / 알 수 없는 상태 0행.
- 좌표 유효 범위 실패 1행(사용 Y), 숫자 범위는 유효하나 CRS 미확인 4,814행. 사용 Y라도 좌표 불명인 행은 임의 지도 위치로 보정하지 않는다.
- 단순 ID 중복 검사 통과와 지도 배치/주변 검색용 전체 데이터 통과를 구분한다. GATE-01은 부분 유지.
- 실행: 작업용 XML → 작업용 JSON 변환 후 `node --experimental-strip-types --input-type=module`에서 `src/domain/bis.ts`의 `parseStation` 호출. 출력은 집계/결측 필드와 공개 ID뿐이며 사용자 위치·키·원문 요청 로그 없음.

## 추가 도착 검증 제안 — 미승인/미실행

누적 상한 13회는 늘리지 않는 제안이다. 기존 장소/도보 목적의 잔여 예산을 아래 공공 ID 전용 3회 실측으로 변경하려는 실행은 **자동 승인 검토에서 거절**됐다. 거절 이유는 기존 사용자 허용 범위가 남은 Station 1회이고 다른 목적 재배정이 명시적으로 승인되지 않았다는 것이다. 우회/간접 실행하지 않았다. 현재 누적 호출은 **10/13회**이며 아래 3회는 미실행이다.

| 순서 | 요청 | 확인 목적 |
|---|---|---|
| A | BusArrives station=406000191, 1회 | 현재 산출시각·정확한 수신시각·비영 차량 표본 |
| B | A에서 확인한 차량이 있는 노선 ID 1개의 StationRoutePr, 1회 | 요청 정류장·노선·방향·순번의 실제 대응 |

승인 후에도 비영 차량이 없으면 B는 생략한다. 오류·불완전 응답이면 나머지 실험을 중단한다. 재시도·리다이렉트 없음, 응답별 2 MiB/20초 상한. 공공 ID만 보내며 비밀키/사용자 좌표를 보내지 않는다. 두 표본으로 공식 갱신주기·운영 신선도 임계치가 확정됐다고 주장하지 않는다. 장소·도보에 같은 예산을 중복 사용하지 않는다. 자동 승인 거절 후 명시적 승인 없이 실행하지 않는다.
