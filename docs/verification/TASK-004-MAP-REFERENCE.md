## 새 앱에 적용한 변경

src/map/sdkLoader.ts로 SDK 로딩 상태 기계를 분리하고 브라우저 어댑터는 naver.ts에 남겼다. 모듈 import만으로 window 접근이나 SDK 요청이 발생하지 않는다. 명시적 지도 동의 흐름에서만 로드하고 동일 페이지의 동시 요청은 하나의 Promise/스크립트를 공유한다. 초기 인증 실패·네트워크 오류·네임스페이스 부재·15초 타임아웃은 pending Promise를 종료하며 실패 뒤 재요청하지 않는다. 타일 실패 및 늦은 인증 실패도 같은 사용 불가 상태를 공유한다. 기존 referrerPolicy=origin과 공개 ID 전달 구조를 유지한다. 이벤트 알림은 한 번만 보내되, 이후 새 Canvas가 실패한 로더를 만나도 해당 화면에는 오류 안내를 직접 설정한다.

src/map/viewport.ts에 네트워크·좌표 저장 없는 픽셀 기하 계산을 분리했다. 목록에서 선택한 정류장이 현재 지도 여백 안에 있으면 지도 이동을 하지 않는다. 화면 밖이면 현재 투영 좌표를 이용해 보이는 영역 중심으로 이동한다. 확대 수준·반경·주변 결과·목록/마커 집합은 변경하지 않는다. 무효 투영값이나 접힌 지도 영역에는 이동하지 않는다. StationMap.tsx는 현재 유효 목록에서 찾은 선택 정류장만 대상으로 한다. 지도 이동은 최초 지도 동의 이후 동작하며 새 SDK 로드를 만들지 않는다.

## 마커 이름·키보드 선택 보완 — 2026-10-29
