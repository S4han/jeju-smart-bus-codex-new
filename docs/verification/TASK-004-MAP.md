# TASK-004 — NAVER 지도·목록 동기화 구현

확인일: 2026-10-29 (Asia/Seoul). **구현 및 모의 SDK 검증 완료, 실제 NAVER 지도/타일 표시 미검증.** 기존 저장소·Vercel·제공자 설정 변경 없음.

## 적용 기준

사용자가 좌표계/개인정보 공식 근거 없이 진행하라고 명시적으로 지시한 범위에서 구현했다. 미확정 보유기간이나 측지계가 공식 확인된 것으로 바꾸지 않는다. 공개 Client ID의 브라우저 전달은 기존 사용자 승인 범위다. Client Secret/버스 비밀키는 전달하지 않는다.

공식 [시작 안내](https://navermaps.github.io/maps.js.ncp/docs/tutorial-2-Getting-Started.html)에서 현재 `ncpKeyId` 로드 형식과 인증 실패 콜백을 확인했고, [Map API](https://navermaps.github.io/maps.js.ncp/docs/naver.maps.Map.html)에서 지도 제거·크기 조정·경계 맞춤 메서드를 확인했다. 문서 예시의 장소·좌표는 앱에 복사하지 않았다. 실제 마커는 현재 공공 정류장 검색 결과만 사용한다.

## 구현

- `src/map/naver.ts`: 명시적 동의 후에만 SDK 스크립트 삽입. 페이지당 공유 로드 1회, 15초 대기 제한, 인증/로딩 실패 후 자동 재시도 없음. 로드 이후 인증 실패도 사용 불가 상태로 유지해 새 지도를 만들지 않는다.
- `src/map/StationMap.tsx`: 출발지/목적지별 지도 동의, 거부 후 목록 이용, 지도·목록 양방향 선택. 선택한 핀은 색과 체크 표시로 구분한다. 지도 영역에 사용자 선택 위치와 공공 정류장이 들어가도록 경계를 맞춘다. 지도 이동 자체는 반경·검색 결과를 바꾸지 않는다.
- 목록과 마커에 `NearbyPanel`의 동일 `results`를 전달한다. 500m→동의 후 1km 결과도 공유한다. 결과를 메모화해 정류장 선택만으로 검색 집합이나 지도 경계가 불필요하게 변경되지 않게 했다.
- 위치 변경/삭제 시 지도를 제거하고 새 위치에는 다시 동의해야 한다. pagehide/unmount도 지도와 이벤트를 제거한다. 이미 실행한 SDK 코드를 확실히 제거하는 동의 철회는 페이지 새로고침으로 구현했다. 모든 위치·정류장 선택과 동의가 초기화된다.
- 런타임 호스트는 기존 등록이 확인된 localhost만 허용한다. 새로운 프리뷰/Vercel 도메인을 등록하거나 재사용하지 않는다. ID 부재·다른 호스트·정적 미리보기에서는 지도 요청 없이 목록을 제공한다.

## 개인정보·식별자·네트워크

지도 안내에는 선택 위치 좌표·지도 영역·이용정보·IP 등이 제공자에 전달·보관·활용될 가능성과 항목별 보유기간 미확정을 표시한다. 거부해도 목록·정류장명 검색은 이용 가능하다. 앱의 동의 상태는 메모리뿐이며 저장소/서버 동의 기록을 추가하지 않았다. 이 구현이 약관상 동의 증빙 또는 법적 적합성 검증을 대신한다는 주장은 하지 않는다.

사용자 좌표는 앱 서버·주소창·앱 로그/저장소로 보내지 않는다. 단, 동의 후 NAVER SDK에는 지도 중심과 공공 마커 좌표를 전달한다. 제공자의 실제 추가 전송/저장 항목은 실측하지 않았다. 앱 자체가 SDK URL에 넣는 것은 공개 ID뿐이며, SDK 로드 요청의 referrer는 좌표 없는 앱 origin만 허용했다.

Vite 빌드는 승인된 공개 지도 ID 하나만 정의 상수로 전달한다. 비밀값 검사에서 서버 비밀키는 계속 금지하고, 공개 ID를 서버 비밀값으로 오분류하던 항목만 수정했다. ID 값·일부·해시를 문서/채팅/테스트 로그로 출력하지 않았다.

실행 앱 CSP는 SDK 호스트 oapi.map.naver.com 및 초기 지도 이미지 호스트 simg/ssl/map.pstatic.net만 명시했다. SDK DOM 스타일을 위해 실행 앱의 인라인 스타일을 허용하되 인라인 스크립트/eval은 허용하지 않는다. 실제 타일 요청 목적지·CSP 완전성은 아직 검증하지 않았으므로 다른 호스트를 임의 일괄 추가하지 않는다. 관리 환경의 외부 허용 호스트는 변경하지 않았다.

독립 HTML은 지도 ID를 비운 별도 빌드로 생성한다. 실행 앱 dist는 보존하며, 독립 파일에 공개 지도 ID/서버 비밀값이 없는지 검사한다. 정적 모드 표시·지도 비활성·외부 스크립트 금지·connect-src none을 유지한다.
