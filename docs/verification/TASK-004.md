사용자 화면의 Index 패널이 비어 있다는 신고를 받았다. 원본 index.html은 Vite가 변환해야 하는 /src/main.tsx를 참조하고 root가 비어 있었으므로 정적 HTML 뷰어에서 앱이 실행되지 않을 수 있다. 사용자의 ChatGPT 미리보기 내부 콘솔에는 접근하지 못해 이 원인을 확정하지는 않았다.

`npm run build:preview`로 빌드된 JavaScript·CSS·공공 정류소 자료를 한 파일 `web-preview.html`에 넣는 생성기를 추가했다. 외부 자산·Vite 서버 없이 표시하고 정류장명 검색·주변 목록을 사용할 수 있다. 실행 코드에서 정적 미리보기 표시를 설정해 HTML 래퍼 처리 방식에 의존하지 않게 했다. 정적 미리보기의 실시간 조회는 비활성이고 CSP connect-src none으로 외부/앱 서버 요청을 차단한다. 인라인 스크립트/스타일은 내용 해시로만 허용하며 키/환경값 비포함 검사를 거친다. 생성 HTML은 재생성 가능한 산출물로 Git에서 제외했다.

원본 index에도 로딩 안내를 넣어 스크립트가 실행되지 않을 때 완전히 빈 화면이 되지 않도록 했다. 실행 앱과 정적 화면 미리보기를 구분하며 실제 앱 조회 기능은 유지한다.

검증: 137개 Vitest·타입/빌드/클라이언트 검사 통과. Chromium의 file:// 접근은 관리 정책으로 차단되어 이를 우회하지 않았고, 허용된 HTML 내용 주입으로 독립 뷰어 환경을 재현했다. 390/1180px에서 화면 표시·정류장 검색/선택·실시간 조회 버튼 비활성·가로 넘침 없음·외부 HTTP 요청/페이지 오류 0건 확인. 검증 도구 `scripts/verify-web-preview.cjs`. ChatGPT 내장 패널 자체에서의 렌더 결과는 미확인이다. UI 열기 도구는 이 호스트에서 사용 불가여서 사용자에게 생성 파일 링크를 제공한다. 외부 서비스 호출·기존 저장소/Vercel/메일 변경 없음.
