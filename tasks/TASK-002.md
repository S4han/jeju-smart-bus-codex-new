# TASK-002 — 실제 API 응답과 개발 게이트 검증

상태: 미착수 / 계획 초안

## 선행 조건
TASK-001의 호출 대상·무료 조건·인증·호출 예산 확인. 위치를 전송할 경우 관련 PRIV 통과. 필요한 자격정보 미확보 시 보류.

## 범위
검증 전용 최소 호출과 비식별 증거 문서만. 서비스 기능 구현 금지.

## 추적 대상
PRIV-001~004, GATE-01~06, U-002/U-006

## 수행 및 완료 기준
공공 정류장 표본으로 정류장 ID/명칭/좌표/좌표계, 노선 방향·정차 순서·ID 정합성, 실시간 산출 시각·단위·시간표 가용성을 확인한다. 도보·대기·버스·환승 구성요소의 시간 기준을 맞추고 중복 없는 산식 및 미확인 조건을 검증한다. API 오류 시 예산 내에서도 반복 호출을 중단한다. 각 게이트별 통과/부분/보류 및 허용 기능 표를 남긴다. 합성 예시는 실호출 증거로 쓰지 않는다.

## 보류·금지 조건
정류장·경로·시간 추천은 각각 PRD 게이트 실패 시 보류. 미확정 환승/도보/산식은 사용자 확인 전 확정 금지.

## 산출물과 검증
관련 설계/증거는 docs/verification/TASK-002.md에 작성한다. 변경 파일·관련 FR/AC·실행한 검증과 결과·미완료 게이트·다음 작업을 보고한다. 코드 작업은 테스트/빌드/개인정보·비밀 점검 증거를 포함한다. 실행하지 않은 검증은 미실행으로 표기한다.
