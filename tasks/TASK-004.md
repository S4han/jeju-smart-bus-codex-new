# TASK-004 — 현재·수동 위치와 정류장·도착정보

최신 위치 표식: 출발/목적 위치 구분 표시 및 개별 동의·독립 정리 구현, 390/1280px 모의 검증 통과. 실제 SDK 배치는 미검증.

지도 마커: 정류장 이름/선택 라벨·44px 접근 가능한 버튼·Enter/Space 선택 및 포커스 보존 구현. 모의 지도/DOM 검증 통과, 실제 배치는 미확인.

소스 참고 구현: SDK 로더 환경 분리 및 화면 밖 선택 정류장으로 지도 이동 구현. Vitest 149개 + Node guard 3개·빌드·모의 브라우저 통과. [참고 기록](../docs/verification/TASK-004-MAP-REFERENCE.md). 실제 지도 성공 미확인·예산 유지.

이전 지도 후속(2026-10-29): CSP 보완, 타일 로딩 대기/20초 실패 처리 및 페이지 내 재시도 차단 구현. Vitest 139개 + Node guard 3개, 타입/빌드/모의 브라우저 검증 통과. 실제 SDK/정적 자산 200이나 nrbe 503으로 타일 표시 실패. SDK 진입 누적 3회·BIS 19/19 유지. [최신 후속 기록](../docs/verification/TASK-004-MAP-FOLLOWUP.md)을 따른다.


상태: 부분 구현. 로컬 위치·정류장명 검색·500m/동의 후 1km 검색 및 실제 도착 조회 연결 구현. 139개 Vitest·3개 Python 테스트·빌드·Chromium 검증 통과. 실제 도착 예측 3개 표시 확인. 지도·목록 동기화는 모의 SDK 검증 완료, 실제 지도 표시·일반 장소명 검색·시간표 대체는 미완료.

현재 실제 연동 재개 조건은 [잔여 조건표](../docs/verification/TASK-004-BLOCKERS.md)를 기준으로 한다. 60초 신선도 기준은 사용자 확정, API는 후속 사용자 추가 호출 지시·실행 후 19/19회 소진, 지도 개인정보/정류장 측지계 등 미확정 조건은 유지한다.

## 선행 조건
TASK-003, PRIV-001~004 통과. 정류장 GATE-01, 도착·시간표 GATE-04, 선택 공급자의 GATE-06 확인.

## 범위

## 추적 대상

## 수행 및 완료 기준
PRD 각 AC의 허용·거부·미선택·실패·빈 데이터·오래된 행을 검증한다. 450/500/550m 경계, 0건일 때 동의 후 1km 및 동의 거부를 확인한다. 지도와 목록은 동일 유효 집합을 사용한다. 시간표 추정은 검증된 대체 원천이 있을 때만 별도 표기한다. 위치 데이터 URL·로그·저장소·공유 캐시 누출을 점검한다.

## 보류·금지 조건
대체 데이터 부재는 안전한 미제공 상태로 기록하고 FR-014 완료를 선언하지 않는다. 신선도 기준 등 수치는 실측·확인 후 정한다.

## 산출물과 검증
관련 설계/증거는 docs/verification/TASK-004.md에 작성한다. 변경 파일·관련 FR/AC·실행한 검증과 결과·미완료 게이트·다음 작업을 보고한다. 코드 작업은 테스트/빌드/개인정보·비밀 점검 증거를 포함한다. 실행하지 않은 검증은 미실행으로 표기한다.
