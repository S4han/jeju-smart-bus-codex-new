# TASK-008 — 전체 AC 통합·KPI·출시 검토

상태: 전체 출시 검토 미착수. 사용자 요청에 따른 Vercel 정적 확인용 배포 준비 및 로컬 산출물 검증 완료, 실제 업로드/URL 발급은 인증 부재로 미실행. [확인용 배포 기록](../docs/verification/VERCEL-REVIEW.md)을 따른다.

## 선행 조건
TASK-004~007 결과, 미완료 FR와 모든 게이트 상태 확보.

## 범위
US-001~008, MVP 19개 FR/AC, NFR·PRIV·GATE 전체.

## 추적 대상
AC-001~018, AC-020; AC-019는 후속 제외 확인

## 수행 및 완료 기준
FR별 구현/테스트/실응답/실기기 증거를 연결한다. 위치 허용·거부, 500m/1km, 정류장 도착, 직행/환승, 미확인 시간, 장애/한도, 지도 실패를 모바일에서 점검한다. 성능·정확도·시간 오차를 실측하고 KPI 목표는 사용자와 확정한다. 실제 청구 0원과 한도 차단, 개인정보 외부 흐름을 확인한다. 검증되지 않은 항목은 미완료로 남겨 출시 가능/보류를 보고한다.

## 보류·금지 조건
배포는 별도 사용자 지시 후 새 Vercel 프로젝트로만. 기존 프로젝트·도메인·환경변수 변경 금지. FR-019는 미구현 정상이며 AC-019 통과로 표기하지 않음.

## 산출물과 검증
